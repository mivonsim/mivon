## Bug mivon yang DIPERBAIK

1. **fmt: escape string literal hilang** (`crates/mivon-tools/src/fmt.rs`)
   Lexer meng-unescape `\n`/`\t`/`\\`/`\"` saat scan; fmt merender nilai decode
   apa adanya → `$display("\n--- X")` pecah baris, `fmt(fmt(s)) != fmt(s)`.
   Fix: re-escape saat render. Regresi `string_escape_roundtrip`.
2. **sim: `extend_to` X-fill pada operand X/Z** (`mivon-simulator/value.rs`)
   `1'bx | 2'b00` salah `2'bxx` (LRM §1800-2017 §11.8.2 unsigned zero-fill →
   `2'b0x`) dan beda dari jalur packed → differential O5 (bug_0793, opentitan
   prim_intr_hw). Fix zero-fill; `sign_extend_to` tak tersentuh.
   Regresi `test_extend_x_operand_is_zero_filled`; replay 5 jalur konsisten.
3. **helper bersama** `Lexer::escape_string_literal` — dipakai fmt + render
   token LSP (backend.rs dulu tanpa escape, kelas bug sama).

## Tugas lanjutan: bug menyamar sbg warning + diag sesat (2026-09-28)

Populasi warning kampanye (agregat seluruh artefak): WR0102=1703, WR0104=103,
E/RT codes (fragment/downgrade), WR0014, WR0301, WR0202, WR0203.

1. **WR0102 = bug lebar menyamar sbg warning (FIXED, c56f3bf)** —
   `compute_expr_width` me-resolve struct field hanya utk obj Ident; rantai
   `a.b.c.d` jatuh ke lebar OBJEK INDUK → synth wire port melebar → flatten
   cukup kasih warning WR0102 (koneksi lebar beda legal) + RT0004, padahal
   lebar SALAH → X-propagation beda antar engine (O5 differential bug_0793).
   Kini resolve sampai leaf (`resolve_member_chain` + `sub_fields` typedef
   berjenjang dgn guard depth). Verifikasi: WR0102=0 RT0004=0 pada kasus.
   Warning WR0102 sisanya = mismatch lebar legal (LRM izinkan implisit
   ext/trunc) — perilaku by-design, bukan bug.
2. **Diag sesat: fragment-downgrade (FIXED, 213514b)** — file yang MENULIS
   module tapi gagal parse ikut diturunkan jadi `warning[Exxxx]: fragment:`
   (label salah + severity salah + gate kesiapan sim menghitung is_error
   saja). Kini turun hanya utk source tanpa konstruk top-level.
3. **Kebijakan degrade (dibiarkan — sadar & terdokumentasi di kode)** —
   generate block gagal diekspansi / generate-if non-const / port width
   fallback 1 memang Warning by design (kom: hindari cascade E3001 hirarki).
   Pesannya eksplisit ("skipped", "fallback lebar 1", "taking true branch")
   → bukan bug tersembunyi; membalik = keputusan produk, bukan fix.
   WR0104/WR0014/WR0202/WR0301 = observasi fakta design, benar sbg warning.
4. **`member access not allowed in constant expression`** (const_eval.rs:843)
   — pada korpus fragment (package struct tak ter-definisi, mis.
   `config_pkg` hilang korpus cva6) → resolve mustahil; flatten struct-param
   default ada (param_util.rs:385-441) utk kasus package lengkap.
